## 0.1.0

- ND0: server core. Per-agent tool registry (deny by default; governed and ungoverned tool sets), scripted deterministic agent planner, tool handlers (policy lookup, human handoff, approval-required credit, and the three commit tools that exist only in the ungoverned set), hash-chained append-only commitment ledger and audit log, five scenarios, API (`/api/health`, `/api/scenarios`, `/api/agents`, `/api/runs`, `/api/ledger`, `/api/audit`, `/api/audit/verify`, `/api/reviews`, `/api/reset`), doctor, Dockerfile and loopback-published compose, gitleaks pre-commit hook, mutation-pinning tests. The web UI is the next step (ND1) and is not built.
- ND1: web UI (React, Vite, @xyflow/react): scenario picker, side-by-side ungoverned and governed columns with transcript and commitment ledger, tool registry, residual-risk panel, diagram with Simulate/Reset/speed, audit trail with Verify, dark and light themes. Server serves `web/dist` with a same-origin-only CSP. `npm run e2e` Playwright run. Dockerfile now builds the UI.
- ND2: fix pass after review. Host guard anchoring, per-rule redaction, tag-block and surrogate reveal, dispatcher argument validation, capacity guards and header details are each pinned by a test and a mutation. The ledger panel no longer shows an all-clear when its view disagrees with the run, and its empty-state copy no longer says the company is not bound. Mutation harness counts only real test failures as kills. Accessibility and narrow-screen fixes. Docs updated: the image was built and run once.
- ND3: packaging. Multi-stage Dockerfile with a `/api/health` HEALTHCHECK and a `.dockerignore`, Learning Hub content pack (`content-pack.json`, generator, ajv validator, schema copy, glossary of 12 terms, four stories, five cards, the residual-risk statement), demo-shelf entry (`docs/shelf-entry.json`, catalog D31) checked by a copy of the shelf's rules and once by the shelf's real validator, README packaging section.
